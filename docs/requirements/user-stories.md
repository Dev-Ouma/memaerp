# Prioritized User Stories

| ID     | Story                                                                                                                                          | Priority                | Acceptance reference    |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- | ----------------------- |
| US-001 | As an applicant, I can save and resume an application so unreliable connectivity does not lose my work.                                        | Must                    | AC-ADM-001              |
| US-002 | As an Admissions Officer, I can evaluate only applications in my assigned scope using approved criteria.                                       | Must                    | AC-AUTH-001             |
| US-003 | As a Registrar, I can matriculate an accepted applicant without creating a duplicate person.                                                   | Must                    | AC-DATA-001             |
| US-004 | As a student, I can register eligible courses and receive precise reasons for rejected selections.                                             | Must                    | AC-REG-001              |
| US-005 | As a Finance Officer, I can reconcile provider transactions and safely resolve exceptions without editing ledger history.                      | Must                    | AC-FIN-001              |
| US-006 | As a Lecturer, I can enter marks for assigned offerings but cannot approve or publish my own submission.                                       | Must                    | AC-GRD-001              |
| US-007 | As a student, I can view only my own published results and download an authentic transcript when eligible.                                     | Must                    | AC-AUTH-001, AC-GRD-001 |
| US-008 | As an HOD, I can view academic records in my department but cannot access another department by changing an identifier.                        | Must                    | AC-AUTH-001             |
| US-009 | As a process owner, I can configure approval routes and thresholds without a code deployment.                                                  | Must                    | AC-WFL-001              |
| US-010 | As an auditor, I can trace a financial or grade change to actor, authority, reason, before/after state, and correlation ID.                    | Must                    | AC-AUD-001              |
| US-011 | As a content editor, I can publish accessible programme and admissions content with approval and rollback.                                     | Must                    | AC-CMS-001              |
| US-012 | As an ICT operator, I can detect failed jobs/integrations and replay safe operations without duplicating business effects.                     | Must                    | AC-OPS-001              |
| US-013 | As a data protection officer, I can fulfill a verified data-subject request while preserving legally required records and third-party privacy. | Must                    | AC-PRV-001              |
| US-014 | As an executive, I can view certified KPIs with lineage to governed source data but cannot alter operational records.                          | Should                  | AC-REP-001              |
| US-015 | As a second institution introduced later, my data can be isolated without retrofitting institution keys into every domain.                     | Architecture constraint | AC-TEN-001              |
